# 영화문화예술제 일일방문증

서울영화초등학교 2026 HAPPY YES! 영화문화예술제(2026. 10. 27.) 일일방문증 페이지입니다.
학년, 반, 이름을 입력하고 "방문증 보기"를 누르면 방문증이 나타납니다.
`index.html` 파일 하나로 동작하고, 서버나 데이터베이스는 필요하지 않습니다.
발급 기록을 구글 시트에 남기는 기능은 선택 사항이며, 아래 "발급 기록 켜기"에서 설정합니다.

## GitHub Pages로 공개하기

1. 이 폴더 안의 파일을 저장소에 올립니다. `index.html`이 저장소 맨 위에 있어야 합니다.
2. 저장소의 **Settings** → 왼쪽 메뉴 **Pages**로 갑니다.
3. **Build and deployment**의 **Source**를 **Deploy from a branch**로 두고, 브랜치(`main`)와 폴더(`/ (root)`)를 고른 뒤 **Save**를 누릅니다.
4. 1~2분 뒤 `https://계정이름.github.io/저장소이름/` 주소로 접속할 수 있습니다.

GitHub Free 요금제에서는 공개(public) 저장소만 Pages를 쓸 수 있습니다. 저장소를 비공개로 두더라도 Pages 사이트는 주소를 아는 사람 누구나 열 수 있습니다.

## 발급 기록 켜기 (선택)

방문증이 만들어질 때마다 발급 시각, 학년, 반, 번호, 이름을 구글 시트에 한 줄씩 남깁니다.
GitHub 페이지는 시트에 직접 쓸 수 없어서, 구글 Apps Script 웹앱이 중간에서 받아 적습니다.

1. 기록용 구글 스프레드시트를 새로 만듭니다. 학생 명단 시트와는 따로 두는 것을 권합니다.
2. 그 시트에서 **확장 프로그램 → Apps Script**를 열고, 기본 코드를 지운 뒤 `tools/apps-script/Code.gs`의 내용을 붙여 넣고 저장합니다.
3. 오른쪽 위 **배포 → 새 배포**에서 유형을 **웹 앱**으로 고르고, **실행 사용자: 나**, **액세스 권한: 모든 사용자**로 두고 배포합니다. 권한 승인 창이 뜨면 승인합니다.
4. 나온 웹 앱 주소(`https://script.google.com/macros/s/…/exec`)를 브라우저로 열어 "켜져 있습니다"라는 문구가 보이는지 확인합니다.
5. `tools/config.example.json`을 `tools/config.json`으로 복사하고 `log_url`에 그 주소를 넣습니다.
6. 저장소 맨 위에서 `python3 tools/build.py`를 실행해 `index.html`을 새로 만들고, GitHub에 다시 올립니다.

주소를 설정하면 입력 화면에 "학년, 반, 이름, 발급 시각이 학교에 기록됩니다"라는 안내 문구가 자동으로 나타납니다.

동작 방식과 알아둘 점은 다음과 같습니다.

- 기록 탭 이름은 `발급기록`이고, 처음 기록될 때 자동으로 만들어집니다.
- 명단 시트(`Code.gs`의 `ROSTER_ID`, `ROSTER_TAB`)와 대조해서 맞는 학생만 기록합니다. 번호는 명단에서 가져옵니다.
- 같은 학생이 방문증을 다시 만들면 그때마다 한 줄이 더 쌓입니다.
- 기록이 실패해도 방문증은 정상으로 나옵니다. 페이지는 기록 결과를 확인하지 않습니다.
- 웹앱 주소는 페이지 소스에 들어 있습니다. 주소를 아는 사람이 실제 학생 이름을 반복해서 보내면 기록 줄이 늘어날 수 있습니다.
- `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 새 버전**으로 다시 배포해야 반영됩니다.
- 명단 시트의 학교 계정 설정에 따라 "모든 사용자" 배포가 막혀 있을 수 있습니다. 막혀 있으면 3번 단계에서 알 수 있습니다.

## 개인정보

- `index.html`에는 학생 이름이 그대로 들어 있지 않고, 학년·반·이름을 변환한 값만 들어 있습니다. 페이지 소스를 열어도 명단이 보이지 않습니다.
- 학생 실명이 든 `tools/roster.csv`는 저장소에 올리지 않습니다. `.gitignore`에 등록해 두었습니다.
- 페이지는 `noindex` 설정이 되어 있어 검색 결과에 나오지 않도록 했습니다.
- 학년·반·이름을 정확히 입력해야 방문증이 나옵니다. 주소를 아는 사람이 학생 이름을 직접 넣어 보면 그 학생의 방문증이 보일 수 있으니, 주소는 학부모에게만 안내해 주세요.
- 발급 기록을 켜면 학생의 학년·반·이름이 기록용 시트에 쌓입니다. 기록용 시트는 공유 범위를 제한하고, 보관과 삭제 기준은 학교 개인정보 지침에 맞춰 정해 주세요.

## 명단 고치기

전학이나 이름 정정이 있으면 `index.html`을 다시 만들어야 합니다.

1. `tools/roster.example.csv`와 같은 형식으로 `tools/roster.csv`를 만듭니다. 열은 `학년,반,번호,성명,비고`입니다. 영문 이름 학생은 비고에 한글 이름을 적습니다.
2. `pip install cryptography`를 한 번 실행합니다.
3. 저장소 맨 위에서 `python3 tools/build.py`를 실행하면 `index.html`이 새로 만들어집니다.
4. 새 `index.html`을 GitHub에 다시 올립니다.

발급 기록을 쓰는 경우, 기록 대조에 쓰이는 명단은 `Code.gs`가 읽는 구글 시트입니다. 이 시트도 같은 내용으로 고쳐 주세요.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 배포용 페이지. 방문증 이미지가 안에 들어 있습니다. |
| `tools/build.py` | 명단으로 `index.html`을 만드는 스크립트 |
| `tools/template.html` | 페이지 원본 (화면 디자인과 동작) |
| `tools/pass-bg.jpg` | 방문증 바탕 이미지 |

| `tools/apps-script/Code.gs` | 발급 기록을 받아 시트에 적는 Apps Script |
| `tools/config.example.json` | 발급 기록 웹앱 주소를 넣는 설정 파일 예시 |
